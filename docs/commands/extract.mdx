# drift-lock extract

`drift-lock extract` scans configured TypeScript source files for `/* @drift */`
contracts and writes the sharded contract index. This is the command that
updates the committed baseline used later by `check`, `diff`, `explain`, and
`proof`.

`extract` is intentionally the only DriftLock command that writes the committed
contract index. Use `extract --check` in CI when you want to verify that the
index is current without modifying the checkout.

## Usage

```bash
drift-lock extract [options]
```

## Options

| Option | Description | Default |
| --- | --- | --- |
| `--root <dir>` | Project root. | Current working directory |
| `--source <dir>` | Source directory to scan. | `.drift/config.json` `source`, or `src` when config is missing |
| `--out <dir>` | Output index store path. | `.drift/config.json` `index`, or `.drift/contracts.generated.index` when config is missing |
| `--check` | Compare the expected generated index with the committed index without writing files. | `false` |

## Examples

Extract contracts using project config:

```bash
drift-lock extract
```

Extract from an explicit source directory:

```bash
drift-lock extract --source packages/core/src
```

Write the index to a custom location:

```bash
drift-lock extract --out .drift/contracts.generated.index
```

Run against a different project root:

```bash
drift-lock extract --root ../my-app
```

Check that the generated index is current without writing it:

```bash
drift-lock extract --check
```

## Output

On success, the command prints the number of extracted contracts and the index
path:

```txt
Extracted 12 @drift contract(s) to .drift/contracts.generated.index.
```

The index directory should be committed when it is part of the project's
DriftLock baseline.

With `--check`, a current index prints:

```txt
Generated DriftLock index is current at .drift/contracts.generated.index.
```

If the generated index is dirty, the command prints the changed repo-relative
paths and exits `1`:

```txt
Generated DriftLock index is dirty at .drift/contracts.generated.index:
- .drift/contracts.generated.index/manifest.json
```

## Exit codes

| Code | Meaning |
| --- | --- |
| `0` | Contracts were extracted and the index was written, or `--check` found the index current. |
| `1` | Extraction failed, config was invalid, the index could not be written, or `--check` found dirty generated index paths. |
